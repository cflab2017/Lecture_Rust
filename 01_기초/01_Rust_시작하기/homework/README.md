# 과제 - 01. Rust 시작하기

## 문제 1 — 자기소개 3줄 출력
- 파일명: `homework_01/src/main.rs`
- 핵심 개념: `println!` 매크로, 변수 보간

### 요구사항
- 변수 `name`, `hobby`, `language` 를 만들어 각각 자기 자신의 값을 담는다.
- `println!` 매크로로 정확히 3줄을 출력한다.
- 형식: `이름: ...`, `취미: ...`, `좋아하는 언어: ...`

### 예상 출력
```
이름: 김루스트
취미: 책 읽기
좋아하는 언어: Rust
```

### 힌트
- `let name = "김루스트";` 처럼 `let` 으로 변수를 정의한다 (자세한 내용은 02편에서).
- 보간은 `"이름: {}", name` 또는 `"이름: {name}"` 두 가지 방식 모두 가능하다.

## 문제 2 — 두 수의 합과 곱
- 파일명: `homework_02/src/main.rs`
- 핵심 개념: `println!` 매크로, 산술 표현식

### 요구사항
- 변수 `a = 7`, `b = 3` 으로 두 정수를 정의한다.
- 두 줄을 출력한다: 합(`a + b`)과 곱(`a * b`).
- 형식: `7 + 3 = 10`, `7 * 3 = 21`.

### 예상 출력
```
7 + 3 = 10
7 * 3 = 21
```

### 힌트
- `let a = 7;`, `let b = 3;` 로 정의한다.
- `println!("{} + {} = {}", a, b, a + b);` 처럼 표현식 결과도 인수로 넘길 수 있다.
