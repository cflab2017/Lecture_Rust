# 과제 - 04. 제어 흐름

## 문제 1 — FizzBuzz
- 파일명: `homework_01/src/main.rs`
- 핵심 개념: `for in 범위`, `if`/`else if`/`else`

### 요구사항
- 1 부터 15 까지 한 줄씩 출력한다.
- 3 의 배수면 `Fizz`, 5 의 배수면 `Buzz`, 둘 다면 `FizzBuzz`, 아니면 숫자를 출력한다.

### 예상 출력
```
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

### 힌트
- 15 의 배수 검사를 먼저 하거나, `(i % 3 == 0, i % 5 == 0)` 튜플 분기를 사용해도 좋다.
- `0..=15` 가 아니라 `1..=15` 임에 주의.

## 문제 2 — 배열 최댓값 찾기
- 파일명: `homework_02/src/main.rs`
- 핵심 개념: `for in` 배열 순회, 가변 변수 갱신

### 요구사항
- 배열 `let nums = [37, 12, 88, 45, 91, 23, 76];` 가 주어진다.
- 최댓값을 찾아 출력한다. `iter().max()` 같은 메서드 사용 없이 `for` 루프로 직접 구현한다.

### 예상 출력
```
배열: [37, 12, 88, 45, 91, 23, 76]
최댓값: 91
```

### 힌트
- `let mut max = nums[0];` 으로 시작한다.
- `for n in nums.iter() { if *n > max { max = *n; } }`.
- 정수는 `Copy` 타입이라 `*n` 으로 역참조해 값을 가져올 수 있다 (참조·빌림은 다음 장에서 자세히).
