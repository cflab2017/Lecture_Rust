# 과제 - 03. 기본 타입

## 문제 1 — 나눗셈의 몫과 나머지
- 파일명: `homework_01/src/main.rs`
- 핵심 개념: 정수/실수 연산, `/` 와 `%`

### 요구사항
- 변수 `a = 17`, `b = 5`.
- 정수 나눗셈의 몫과 나머지를 출력한다.
- 실수 나눗셈 결과도 별도로 출력한다 (소수 둘째 자리까지).

### 예상 출력
```
17 ÷ 5 = 3, 나머지 2
17.0 / 5.0 = 3.40
```

### 힌트
- 정수: `a / b`, `a % b`.
- 실수: `a as f64 / b as f64`.
- 소수 자리 포맷: `{:.2}`.

## 문제 2 — 배열 평균
- 파일명: `homework_02/src/main.rs`
- 핵심 개념: 배열 `[T; N]`, 이터레이터 `sum`

### 요구사항
- 배열 `let scores = [85, 90, 78, 92, 88, 70];` 가 주어진다.
- 총합과 평균(소수 둘째 자리까지)을 출력한다.

### 예상 출력
```
점수: [85, 90, 78, 92, 88, 70]
총합: 503
평균: 83.83
```

### 힌트
- `scores.iter().sum::<i32>()` 또는 `let sum: i32 = scores.iter().sum();`.
- 평균은 실수 계산이 필요하므로 `as f64`.
- 배열 자체 출력은 `{:?}` (Debug 포맷).
