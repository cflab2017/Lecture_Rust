# 과제 - 02. 변수·상수·섀도잉·타입 추론

## 문제 1 — 가변 카운터
- 파일명: `homework_01/src/main.rs`
- 핵심 개념: `let mut`, 산술 대입

### 요구사항
- `let mut counter = 0;` 로 시작한다.
- counter 를 차례대로 `+5`, `*3`, `-2` 한 뒤 매 단계마다 값을 출력한다.
- 마지막 줄에 최종 값을 출력한다.

### 예상 출력
```
시작: 0
+5 후: 5
*3 후: 15
-2 후: 13
최종: 13
```

### 힌트
- `counter += 5;`, `counter *= 3;`, `counter -= 2;` 를 사용한다.
- `mut` 없이 시도하면 컴파일이 막힌다는 사실을 확인해 보세요.

## 문제 2 — 섀도잉으로 타입 변환
- 파일명: `homework_02/src/main.rs`
- 핵심 개념: 섀도잉, 타입 바꾸기

### 요구사항
- `let input = "12345";` 로 문자열을 정의한다.
- 같은 이름 `input` 으로 섀도잉하여 `i32` 로 변환한다.
- 변환된 값에 100을 더한 값을 출력한다.

### 예상 출력
```
원본 문자열: 12345
정수 변환: 12345
+100: 12445
```

### 힌트
- `let input: i32 = input.parse().expect("숫자가 아님");`
- 섀도잉은 `mut` 없이 같은 이름을 다시 `let` 으로 묶는 것이다.
