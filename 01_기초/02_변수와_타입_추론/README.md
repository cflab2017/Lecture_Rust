# 02. 변수·상수·섀도잉·타입 추론

Rust 의 변수는 기본적으로 **불변(immutable)** 입니다. 다른 언어의 "변수" 보다 훨씬 보수적인 출발점이지만, 그 덕에 동시성·메모리 안전성을 정적으로 보장할 수 있습니다. 이 강의에서는 `let` 의 기본 동작, `mut` 와 섀도잉의 차이, 상수(`const`/`static`), 그리고 타입 추론·명시 문법을 익힙니다.

## 학습 목표

- `let` 으로 묶은 값이 기본 불변이라는 사실을 이해하고 `let mut` 와 구분한다.
- 섀도잉(shadowing)으로 같은 이름의 새 변수를 덮어쓰는 방식을 익힌다.
- `const` 와 `static` 의 차이, 그리고 명시 타입의 필요성을 설명한다.
- Rust 의 타입 추론이 어떻게 동작하는지 알고, 필요한 곳에 타입을 명시한다.

## 핵심 개념

### 1) `let` — 기본은 불변

```rust
let x = 10;
x = 20; // ❌ cannot assign twice to immutable variable `x`
```

불변이 기본인 이유는 단순합니다. **읽기 전용** 으로 시작하면, 나중에 코드를 읽을 때 "이 값은 어디서 바뀌었지?" 를 추적할 필요가 없습니다. 데이터 레이스도 줄어듭니다.

### 2) `let mut` — 명시적으로 가변

값이 정말 바뀌어야 할 때는 `mut` 을 붙입니다. 단, 같은 변수에 **다른 타입** 을 대입하는 것은 여전히 안 됩니다.

```rust
let mut count = 0;
count += 1;       // OK
// count = "0";   // ❌ 타입은 못 바꿈
```

### 3) 섀도잉 — `let` 으로 같은 이름 다시 묶기

`let name = ...;` 을 한 번 더 쓰면 같은 이름이지만 **새 변수** 가 만들어집니다. `mut` 와의 핵심 차이는 두 가지입니다.

- 타입을 바꿀 수 있다 (예: `&str` → `usize`).
- 기존 변수는 그대로 두고 그 위에 새 변수를 "겹쳐 둔다" — 그래서 섀도잉(shadowing).

### 4) `const` 와 `static`

| 키워드 | 평가 시점 | 타입 명시 | 메모리 | 변경 |
|--------|-----------|-----------|--------|------|
| `let`     | 런타임     | 추론·명시 | 스택/힙 | `mut` 시만 |
| `const`   | 컴파일타임 | **필수**  | 인라이닝 | 불가 |
| `static`  | 런타임 시작 | **필수** | 고정 주소 | `unsafe` 필요 |

상수 이름은 관례상 `SCREAMING_SNAKE_CASE` 입니다.

### 5) 타입 추론과 명시

대부분의 변수는 우변 값으로 타입을 추론합니다. 추론이 모호한 자리에서는 명시가 필요합니다.

```rust
let parsed: i32 = "42".parse().expect("숫자가 아님"); // parse 의 반환 타입이 모호
let pi = 3.14f32;                                   // 접미사로도 명시 가능
```

## 예제로 보기

### 예제 1 — `ex01_basics.rs` : 불변과 가변

```rust
// 2편 예제 1: let 불변 변수와 let mut 가변 변수
// `cargo run --bin ex01_basics`

fn main() {
    // 기본 변수는 "불변" 입니다. 한 번 묶은 값은 다시 바꿀 수 없습니다.
    let x = 10;
    println!("x = {x}");

    // 같은 변수에 다시 대입하려면 `mut` 키워드가 필요합니다.
    let mut y = 5;
    println!("처음 y = {y}");
    y = y + 1;
    println!("증가 후 y = {y}");

    // 타입을 명시할 수도 있습니다. (생략하면 Rust 가 추론)
    let pi: f64 = 3.14;
    let flag: bool = true;
    println!("pi = {pi}, flag = {flag}");
}
```

### 예제 2 — `ex02_shadowing.rs` : 섀도잉

```rust
// 2편 예제 2: 섀도잉 — 같은 이름으로 새 변수를 덮어쓰기
// `cargo run --bin ex02_shadowing`

fn main() {
    // 섀도잉은 `let` 으로 같은 이름을 다시 묶는 것입니다.
    // `mut` 와 달리 타입도 바꿀 수 있고, 결과적으로 "새 변수" 가 됩니다.
    let value = 5;
    let value = value + 1;       // 6
    let value = value * 2;       // 12
    println!("value = {value}");

    // 타입을 바꾸는 섀도잉
    let spaces = "   ";          // &str
    let spaces = spaces.len();   // usize
    println!("공백 길이 = {spaces}");

    // mut 로는 불가능: 다른 타입을 대입하면 컴파일 에러.
    // let mut s = "   "; s = s.len(); // ❌
}
```

### 예제 3 — `ex03_consts.rs` : 상수와 숫자 리터럴

```rust
// 2편 예제 3: const 와 static
// `cargo run --bin ex03_consts`

// const 는 컴파일 타임에 결정되며, 타입을 반드시 명시합니다.
const MAX_USERS: u32 = 100_000;

// static 은 프로그램 수명 내내 같은 메모리에 존재합니다.
static APP_NAME: &str = "Lecture_Rust";

fn main() {
    println!("APP_NAME  = {APP_NAME}");
    println!("MAX_USERS = {MAX_USERS}");

    // 숫자 리터럴 안의 `_` 는 가독성 구분자 (값에는 영향 없음)
    let big = 1_000_000;
    println!("big = {big}");

    // 타입 접미사 — 23i64, 1.5f32 처럼 명시 가능
    let count = 23i64;
    let ratio = 1.5f32;
    println!("count = {count}, ratio = {ratio}");
}
```

## 자주 하는 실수

### Q. `mut` 가 있는데 왜 굳이 섀도잉을 쓰나요?

A. 섀도잉은 **타입을 바꾸는 변환** 을 자연스럽게 표현할 때 유용합니다. 예를 들어 입력 문자열을 숫자로 변환할 때 `let input: String = ...;` → `let input: i32 = input.parse()...;` 처럼 같은 이름으로 형태만 바꿀 수 있습니다. `mut` 는 같은 변수의 값만 갱신할 때 씁니다.

### Q. `const` 와 `let` 의 차이가 헷갈려요.

A. `const` 는 컴파일타임에 값이 확정되어야 하고 타입을 반드시 명시합니다(예: `const PI: f64 = 3.14;`). `let` 은 런타임 값도 받을 수 있고 타입은 보통 추론합니다. 함수 내부 상수처럼 보이는 것도 가능하면 `const` 로 두면 의도가 분명해집니다.

### Q. 정수 리터럴 `1_000_000` 의 밑줄은 뭔가요?

A. 가독성을 위한 구분자입니다. `1000000` 과 완전히 같은 값이고, 위치는 자유입니다(`1_00_00_00` 도 같음). 큰 숫자나 16진수(`0xFF_FF`)에 자주 씁니다.

### Q. 타입은 항상 명시해야 하나요?

A. 보통은 명시하지 않아도 컴파일러가 추론합니다. 다만 `.parse()` 처럼 반환 타입이 일반화되어 있는 경우, 변수에 타입을 적어 주거나 `parse::<i32>()` 처럼 터보피시 문법을 써야 합니다.

## 정리

- 변수의 기본은 불변, 가변은 `mut` 로 명시한다.
- 섀도잉은 같은 이름으로 **새 변수** 를 만들고 타입도 바꿀 수 있다.
- `const` 는 컴파일타임 상수, `static` 은 프로세스 수명 내내 살아 있는 정적 변수.
- 타입 추론은 강력하지만 모호할 때는 명시(`let x: i32 = ...;` 또는 터보피시).
