# 과제 - 05. 함수와 표현식

## 문제 1 — 최댓값 함수
- 파일명: `homework_01/src/main.rs`
- 핵심 개념: 함수 정의, 매개변수, 반환값

### 요구사항
- 두 `i32` 를 받아 더 큰 값을 돌려주는 함수 `max_of(a: i32, b: i32) -> i32` 를 정의한다.
- `main` 에서 세 쌍을 호출해 출력한다: (3, 7), (10, 4), (-2, -5).

### 예상 출력
```
max(3, 7) = 7
max(10, 4) = 10
max(-2, -5) = -2
```

### 힌트
- `if a > b { a } else { b }` 를 그대로 반환값으로 쓸 수 있다.
- 세미콜론 위치에 주의: 마지막 줄은 표현식이어야 한다.

## 문제 2 — 섭씨/화씨 변환
- 파일명: `homework_02/src/main.rs`
- 핵심 개념: 함수 두 개, 표현식 반환, 문서화 주석

### 요구사항
- `celsius_to_fahrenheit(c: f64) -> f64` 와 `fahrenheit_to_celsius(f: f64) -> f64` 두 함수를 정의한다.
- 각 함수에 `///` 문서화 주석을 한 줄 이상 적는다.
- 두 호출을 main 에서 보여 준다: 25°C → ?°F, 98.6°F → ?°C.
- 출력은 소수 첫째 자리까지.

### 예상 출력
```
25.0°C = 77.0°F
98.6°F = 37.0°C
```

### 힌트
- °F = °C × 9 / 5 + 32
- °C = (°F − 32) × 5 / 9
- 포맷: `{:.1}`.
