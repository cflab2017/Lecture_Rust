# 05. 함수·표현식·반환값·문서화 주석

Rust 의 함수는 다른 언어와 비슷해 보이지만 두 가지를 꼭 기억해야 합니다. (1) **매개변수와 반환 타입을 모두 명시** 하고, (2) **블록의 마지막 표현식이 반환값** 입니다. 이 두 규칙을 익히면 Rust 의 표현식 지향 스타일이 자연스러워집니다.

## 학습 목표

- `fn` 키워드로 함수를 정의하고 매개변수·반환 타입을 명시한다.
- "표현식" 과 "문장" 의 차이를 이해하고 `return` 없이 값을 돌려준다.
- 블록 `{ ... }` 자체가 표현식임을 활용해 코드를 짧게 쓴다.
- `///` 문서화 주석을 작성하고 `cargo doc` 으로 문서를 만든다.

## 핵심 개념

### 1) 함수 정의 문법

```rust
fn 이름(매개변수: 타입, ...) -> 반환타입 {
    // 본문
}
```

- 매개변수 타입은 **필수**.
- 반환 타입이 `()` (유닛)인 경우 생략 가능.
- 함수 이름·매개변수 이름은 `snake_case`.

### 2) 표현식 vs 문장

- **문장(statement)** 은 값이 없는 코드. `let x = 5;` 처럼 세미콜론으로 끝남.
- **표현식(expression)** 은 값을 가지는 코드. `5 + 3`, `if a { 1 } else { 2 }`, 블록 `{ ... }`.
- 함수의 마지막 줄에 세미콜론을 빼면 표현식 → 반환값이 됩니다.

```rust
fn double(x: i32) -> i32 {
    x * 2 // 세미콜론 없음 → 반환값
}
```

세미콜론을 붙이면 `()` 가 되어 반환 타입 불일치로 컴파일 에러가 납니다.

### 3) `return` 도 쓸 수 있다

조기 종료가 필요하면 명시적 `return` 도 사용합니다. 다만 함수 끝에서의 명시적 `return` 은 관용적으로 잘 쓰지 않습니다.

### 4) 문서화 주석 `///`

함수·구조체·모듈 위에 `///` 로 시작하는 주석을 적어 두면 `cargo doc` 이 HTML 문서를 생성합니다. Rust 표준 문서가 모두 이렇게 만들어집니다.

```rust
/// 두 정수의 합을 반환합니다.
fn sum(a: i32, b: i32) -> i32 { a + b }
```

`cargo doc --open` 으로 브라우저에서 결과를 바로 볼 수 있습니다.

## 예제로 보기

### 예제 1 — `ex01_basic.rs` : 함수의 기본

```rust
// 5편 예제 1: 함수 정의·호출, 매개변수와 반환값

// 매개변수에는 타입을 반드시 명시한다.
// `-> i32` 가 반환 타입.
fn add(a: i32, b: i32) -> i32 {
    a + b // 세미콜론 없음 → 표현식 → 반환값
}

// 반환값이 없는 함수의 반환 타입은 유닛 `()`. 생략 가능.
fn greet(name: &str) {
    println!("안녕하세요, {name}!");
}

fn main() {
    let sum = add(3, 4);
    println!("3 + 4 = {sum}");

    greet("Rust");

    // 함수 안에서 다른 함수를 호출할 수 있다.
    let total = add(add(1, 2), add(3, 4));
    println!("total = {total}");
}
```

### 예제 2 — `ex02_expr.rs` : 표현식과 문장

```rust
// 5편 예제 2: 표현식(expression) vs 문장(statement)
// 핵심: 세미콜론이 있으면 "문장", 없으면 "표현식".

fn double(x: i32) -> i32 {
    let y = x + x; // `let ...;` 는 문장 (값이 없음)
    y              // 마지막 줄에 세미콜론이 없으니 표현식 = 반환값
}

// 블록 `{ ... }` 도 표현식이다. 마지막 식의 값이 블록의 값이 된다.
fn classify(score: i32) -> &'static str {
    let result = {
        if score >= 60 {
            "통과"
        } else {
            "재시험"
        }
    };
    result
}

// 명시적인 early return 도 가능
fn abs(x: i32) -> i32 {
    if x < 0 {
        return -x;
    }
    x
}

fn main() {
    println!("double(7) = {}", double(7));
    println!("classify(55) = {}", classify(55));
    println!("classify(75) = {}", classify(75));
    println!("abs(-9) = {}", abs(-9));
    println!("abs(9)  = {}", abs(9));
}
```

### 예제 3 — `ex03_docs.rs` : 문서화 주석

```rust
// 5편 예제 3: 문서화 주석(///)
// 함수 위에 `///` 를 적어두면 `cargo doc` 으로 HTML 문서를 생성할 수 있습니다.

/// 두 정수의 합을 계산합니다.
///
/// # 예시
/// ```
/// // (doctest 예시는 라이브러리 크레잇에서 실행됩니다.)
/// let s = 1 + 2;
/// assert_eq!(s, 3);
/// ```
fn sum(a: i32, b: i32) -> i32 {
    a + b
}

/// 섭씨를 화씨로 변환합니다.
///
/// 공식: `°F = °C * 9 / 5 + 32`
fn celsius_to_fahrenheit(c: f64) -> f64 {
    c * 9.0 / 5.0 + 32.0
}

fn main() {
    println!("sum(2, 3) = {}", sum(2, 3));
    println!("0°C  -> {:.1}°F", celsius_to_fahrenheit(0.0));
    println!("100°C -> {:.1}°F", celsius_to_fahrenheit(100.0));

    println!();
    println!("문서 생성: `cargo doc --open` 으로 브라우저에서 확인할 수 있습니다.");
}
```

## 자주 하는 실수

### Q. 반환값 줄 끝에 세미콜론을 붙였더니 에러가 납니다.

A. 세미콜론을 붙이면 그 줄은 "문장(statement)" 이 되고 값이 `()` 가 됩니다. 반환 타입이 `i32` 인데 `()` 를 돌려주려 하니 타입이 안 맞는 거죠. 마지막 표현식의 세미콜론을 빼거나 `return value;` 를 쓰세요.

### Q. 매개변수 타입을 생략하면 안 되나요?

A. 본문에서는 추론되지만 **함수 시그니처에서는 항상 명시** 해야 합니다. 시그니처를 보고 호출자/사용자가 의도를 파악하는 것이 Rust 의 설계 철학입니다.

### Q. `///` 와 `//` 는 어떻게 다르나요?

A. `//` 는 일반 주석, `///` 는 **문서화 주석** 이라 `cargo doc` 이 자동 수집합니다. `///` 안에 마크다운을 그대로 쓸 수 있고, ```` ``` ```` 코드 블록은 `cargo test` 의 doctest 로 실행되기도 합니다.

### Q. 함수 인수에 기본값을 줄 수 있나요?

A. Rust 는 기본 인수·이름 인수를 언어 차원에서 지원하지 않습니다. 빌더 패턴이나 `Option<T>` 매개변수, 별도 함수 오버로드를 통해 비슷한 효과를 냅니다.

## 정리

- 함수 시그니처는 `fn 이름(매개변수: 타입) -> 반환타입`.
- 마지막 줄의 세미콜론을 빼면 그 표현식이 반환값이 된다.
- 블록 `{ ... }` 자체도 표현식이라 변수에 묶을 수 있다.
- `///` 문서화 주석 + `cargo doc` 으로 문서를 자동 생성한다.
