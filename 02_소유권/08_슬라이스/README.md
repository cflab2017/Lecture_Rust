# 08. 슬라이스 — `&str` 와 `&[T]`

슬라이스(slice)는 컬렉션의 **연속된 일부분** 을 빌려 보는 참조입니다. 문자열은 `&str`, 배열·벡터는 `&[T]` 라는 슬라이스 타입으로 표현되고, 두 경우 모두 "포인터 + 길이" 의 작은 구조체로 동작합니다. 슬라이스를 익히면 함수 시그니처가 훨씬 자연스러워집니다.

## 학습 목표

- `&str` 와 `String` 의 차이를 이해하고 함수 매개변수로 `&str` 을 선호한다.
- 배열·벡터의 일부 구간을 `&[T]` 로 빌려 처리한다.
- `[start..end]` / `[..end]` / `[start..]` / `[..]` 슬라이싱 문법을 외운다.
- `first_word` 같은 패턴으로 슬라이스를 반환하는 함수를 작성한다.

## 핵심 개념

### 1) 슬라이스란?

> 슬라이스는 **포인터 + 길이** 두 필드를 가진 작은 참조형 타입입니다. 원본 데이터를 복사하지 않고 가리킵니다.

| 슬라이스 타입 | 가리키는 원본 |
|---------------|----------------|
| `&str`        | `String`, `&'static str`(문자열 리터럴) |
| `&[T]`        | `[T; N]` 배열, `Vec<T>`, 또는 다른 슬라이스 |

### 2) 슬라이싱 문법

```rust
let s = String::from("hello world");
&s[0..5];   // "hello"
&s[6..];    // "world"
&s[..];     // 전체

let a = [10, 20, 30, 40];
&a[1..3];   // [20, 30]
```

문자열 슬라이스에서 범위는 **바이트 단위** 입니다. UTF-8 의 문자 경계가 아닌 곳에서 잘라내면 런타임 패닉이 납니다.

### 3) 매개변수는 `&str` / `&[T]` 가 권장

함수가 슬라이스 타입을 받으면 호출자는 `String` 도 배열도 벡터도 그대로 넘길 수 있어 호환성이 좋습니다.

| 매개변수 | 호환 가능한 호출 |
|----------|------------------|
| `&str`   | `&String`, `&'static str`("...") |
| `&[T]`   | `&[T; N]`, `&Vec<T>` |

### 4) `first_word` 패턴

```rust
fn first_word(s: &str) -> &str {
    for (i, &b) in s.as_bytes().iter().enumerate() {
        if b == b' ' { return &s[..i]; }
    }
    s
}
```

반환된 `&str` 은 입력 `s` 의 일부분을 가리킵니다. 라이프타임은 입력에서 자동 추론됩니다(다음 편 9 강에서 자세히).

## 예제로 보기

### 예제 1 — `ex01_str_slice.rs` : 문자열 슬라이스

```rust
// 8편 예제 1: 문자열 슬라이스 &str
//
// String 의 일부분을 빌리는 타입이 &str 입니다.
// 문자열 리터럴 "abc" 도 사실은 &'static str 입니다.

fn main() {
    let s = String::from("Hello, World!");

    // 범위는 [시작..끝). 끝은 제외.
    let hello: &str = &s[0..5];
    let world: &str = &s[7..12];
    let all: &str = &s[..]; // 전체

    println!("hello = {hello}");
    println!("world = {world}");
    println!("all   = {all}");

    // &str 받는 함수는 String 도 받을 수 있다 (deref 변환)
    print_len("Rust");
    print_len(&s);
}

fn print_len(s: &str) {
    println!("\"{s}\" 의 바이트 길이: {}", s.len());
}
```

### 예제 2 — `ex02_arr_slice.rs` : 배열·벡터 슬라이스

```rust
// 8편 예제 2: 배열/벡터 슬라이스 &[T]
//
// 배열·벡터의 연속된 일부분을 빌리는 타입이 &[T] 입니다.

fn sum(nums: &[i32]) -> i32 {
    let mut total = 0;
    for n in nums {
        total += n;
    }
    total
}

fn main() {
    let arr = [10, 20, 30, 40, 50];
    let vec = vec![1, 2, 3, 4, 5];

    // 배열·벡터의 전체를 슬라이스로 빌리기
    println!("배열 전체 합 = {}", sum(&arr));
    println!("벡터 전체 합 = {}", sum(&vec));

    // 일부 구간 빌리기
    let mid: &[i32] = &arr[1..4]; // 20, 30, 40
    println!("arr[1..4] = {:?}, 합 = {}", mid, sum(mid));
}
```

### 예제 3 — `ex03_first_word.rs` : 첫 단어 슬라이스

```rust
// 8편 예제 3: first_word — 슬라이스의 고전적 예시
//
// 문자열에서 첫 공백 직전까지의 슬라이스를 돌려준다.
// 인덱스(usize) 만 돌려주는 것보다 슬라이스가 안전합니다.

fn first_word(s: &str) -> &str {
    for (i, &b) in s.as_bytes().iter().enumerate() {
        if b == b' ' {
            return &s[..i];
        }
    }
    s
}

fn main() {
    let sentence = String::from("Rust 는 시스템 언어입니다");
    let word = first_word(&sentence);
    println!("첫 단어: {word}");

    // 문자열 리터럴에도 그대로 적용 가능
    let lit = "Hello World";
    println!("첫 단어(lit): {}", first_word(lit));
}
```

## 자주 하는 실수

### Q. `&s[0..3]` 으로 한글을 잘랐더니 패닉이 납니다.

A. 문자열 슬라이싱은 바이트 단위입니다. UTF-8 한 글자 중간에서 잘라내면 패닉이 발생합니다. 안전하게 처리하려면 `s.char_indices()` 로 문자 경계를 알아낸 뒤 잘라야 합니다(다음 편들의 10편에서 깊게 다룹니다).

### Q. 슬라이스를 만든 뒤 원본이 수정되면 어떻게 되나요?

A. 빌림 규칙이 그것을 막습니다. `&s[0..5]` 가 살아 있는 동안 `s` 를 수정하려 하면 컴파일 에러가 납니다 — "cannot borrow as mutable".

### Q. `&Vec<T>` 와 `&[T]` 중 어느 쪽을 받아야 하나요?

A. 거의 항상 `&[T]` 입니다. 호출자가 배열·벡터·다른 슬라이스 모두에서 호출할 수 있고, 라이브러리 호환성이 좋습니다.

### Q. 슬라이스는 가변일 수도 있나요?

A. 네. `&mut [T]` 는 슬라이스 원소를 수정할 수 있는 가변 슬라이스입니다. 예: `arr.sort()` 는 내부적으로 `&mut [T]` 를 사용합니다.

## 정리

- 슬라이스 `&str` / `&[T]` 는 컬렉션의 일부분을 가리키는 작은 참조다.
- 슬라이싱 문법은 `[start..end]`, `[..end]`, `[start..]`, `[..]`.
- 함수 매개변수는 `String` 대신 `&str`, `Vec<T>` 대신 `&[T]` 로 받으면 더 일반적이다.
- 문자열 슬라이싱은 바이트 단위 — 멀티바이트 문자 중간을 자르면 패닉.
