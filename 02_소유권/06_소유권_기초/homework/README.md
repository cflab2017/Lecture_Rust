# 과제 - 06. 소유권 기초

## 문제 1 — 두 변수의 길이를 함께 출력
- 파일명: `homework_01/src/main.rs`
- 핵심 개념: `String` 의 소유권 이동을 피하는 방법(반환 또는 clone)

### 요구사항
- `let s = String::from("Rust");` 를 만든다.
- `len_of` 함수를 호출해 길이를 받는다.
- **호출 후에도** `s` 자체를 다시 사용할 수 있어야 한다.
- 마지막 줄에 `Rust 의 길이는 4 입니다.` 를 출력한다.

### 예상 출력
```
Rust 의 길이는 4 입니다.
```

### 힌트
- 두 가지 풀이가 가능합니다.
  - (A) 함수가 `(String, usize)` 튜플을 반환하도록 만들어 String 을 돌려받기.
  - (B) `s.clone()` 으로 복제해서 함수에 넘기기. (비용이 듭니다)
- 정답은 (A) 방식을 사용합니다 — 다음 편에서 배울 참조 없이도 풀 수 있는 가장 자연스러운 방법.

## 문제 2 — i32 는 복사된다
- 파일명: `homework_02/src/main.rs`
- 핵심 개념: `Copy` 트레잇 타입의 동작

### 요구사항
- 변수 `let n = 42;` 를 만든다.
- 함수 `print_squared(n: i32)` 가 `n * n` 을 출력하도록 정의한다.
- `print_squared(n);` 을 호출한 뒤 `main` 에서 다시 `n` 을 출력해 보여 준다.

### 예상 출력
```
제곱: 1764
원본: 42
```

### 힌트
- `i32` 는 `Copy` 라 함수에 넘긴 뒤에도 원본을 계속 사용할 수 있습니다.
- `println!("제곱: {}", n * n);` 처럼 작성합니다.
